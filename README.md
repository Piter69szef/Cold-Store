CØLD | Official Store

Welcome to the official repository for the CØLD streetwear storefront. This web platform serves as the landing page and catalog showcase for the CØLD apparel line, featuring custom-designed streetwear items integrated with print-on-demand fulfillment.

❄️ Brand Overview

CØLD is an independent streetwear brand built around bold, minimalist typography, modern dark-mode aesthetics, and premium-quality apparel.

Motto / Theme: CØLD A$ F_CK / CØLD I$ F!RE

Platform: Spring (formerly Teespring) Print-On-Demand (POD) integration

Visual Identity: Dark theme (#0a0a0a), vibrant crimson accents (#ba0000), bold geometric branding.

✨ Features

📱 Fully Responsive Layout: Optimized for seamless display across mobile, tablet, and desktop devices.

🎨 Dynamic Product Preview: Interactive view toggling (Front / Back product views) directly in the product grid.

🛒 Interactive Cart System: Client-side cart state management for smooth browsing experience.

⚡ Lightweight & Fast: Zero external runtime dependencies for maximum load speed.

🎯 Fulfillment Ready: Direct product routing to Spring/Teespring checkout flows.

🛠️ Tech Stack

HTML5: Semantic markup structure.

CSS3: Custom CSS variables, flexbox, and responsive CSS grid layout.

JavaScript (Vanilla ES6+): Dynamic product rendering and UI state toggling.

Hosting: GitHub Pages.

🚀 Deployment & Local Setup

Running Locally

Clone or download the repository files (index.html and parafka logo.png).

Keep both files in the same directory.

Open index.html in any modern browser (Chrome, Opera, Firefox, Edge).

Live Hosting via GitHub Pages

Go to repository Settings -> Pages.

Select main branch as the source and click Save.

Access the live site via https://Piter69szef.github.io/Cold-Store/.

👕 Print-on-Demand (POD) Integration

Product creation, printing, shipping, and payment processing are powered by Spring (Teespring). Each product action maps to the corresponding store listing page on Spring's platform.
